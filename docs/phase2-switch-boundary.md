# Phase 2 学生往返切换边界补证

固定原版 `8ede9c985c3518f4bd622db8bcf9c1e0d6c9d927` 在实际 Windows 隔离应用复现：A 选择成绩趋势，切到 B 且不点 B 的任何页签，再回 A，显示成绩趋势；预期家长诉求。旧选择只因 studentId 不同而暂时不生效，没有被真正清除。

修复在检测到实际渲染的学生 ID 变化时清除该组件旧的显式选择。有效页签仍按当前可用模块推导；React 在提交前重试此组件自身的渲染，不卸载整个 StudentDetail、不改业务面板 key、不清理草稿或写入回执。同一学生保存、刷新不会触发清除。

可重复回归：`node scripts/profile-acceptance.cjs <隔离EXE> <证据目录> boundary-proof`。原版断言失败为“成绩趋势 !== 家长诉求”，候选通过。完整 candidate 模式也包含同一 A-B-A 回归，并继续检查同学生保存刷新、草稿、busy、待确认请求、延迟响应与 20 人切换。

没有数据库、IPC、payload 或备份格式变更。本轮补证用于联合候选准备，不代表正式升级获准。
