# Batch 5 学习过程数据接口

`weeklyReview(studentId, { from, to })` 返回单个学生的 `WeekFacts`、当前事实摘要及历史快照。所有日期使用 Asia/Shanghai。自然周为周一至周日，机构工作周为周二至周日。调用方也可传入 1 至 31 天的明确日期范围。

| 后续材料 | 事实来源 | 人工填写 |
| --- | --- | --- |
| 学生每周学习进度表 | `facts`、`plans`、`tracking`、`visits`。保留学习历史身份、详细任务身份与规划修订。 | 学习评价和应对措施可取用户已确认的复盘字段。 |
| 月度家校沟通表 | 对自然月范围读取 `contacts`、已保存的学习与成绩事实、`followUps`。 | 用户决定家长沟通重点及完整陈述。 |
| 多学生每周学习复盘 | `weeklyLearningManagement` 提供按周筛选的学生清单及复盘状态；逐个使用 `weeklyReview` 读取来源数据或明确选择已确认快照。 | 复盘评价、问题判断、下周干预及家长沟通重点。 |

实际到课按签到身份统计。时长仅使用已登记的签到签退并合并同一学生重叠区间。有效学习时间、占比、健康度、作业完成率、前后正确率和知识掌握百分比缺少确认口径时保留未登记。合成验收覆盖规划来源待核对的排除规则。机构模板仅作本机结构核对，打印版式留待后续批次。

Schema v16 在独立恢复中新增快速登记明细、单元检测事件及复盘快照三张表，SWBACK2 格式不变。业务导出保留三张表及版本身份。v16 不能向旧 v13 强制降级，回退需要保留最新 v16 备份和独立档案。
