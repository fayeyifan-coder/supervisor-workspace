# Batch 2E：完整备份入口与全量业务导出

基线为合并 #22 后的 main `cd43c0f11b12c3019aa7056cfe0ce1d424d6b7dc`。维护补证、E1、E2 各有独立提交和 Draft PR；尚未批准安装新正式版本。

页头“数据导出与备份”打开常驻面板，不卸载学生表单。E1 的“一键完整备份”复用原 SWBACK API、引擎、校验、恢复和成功备份状态。E2 单独导出可阅读 XLSX、保真 JSON、范围/摘要清单和最终完成标记；不会记成一次完整备份。

## 范围与映射

仅支持当前 SWBACK2 五库 / M1 v6，不迁移旧档案。`business-export-schema.ts` 白名单逐项适配 24 表及全部字段；源布局不匹配则拒绝导出。21 表的全部业务行、版本和关联身份均保留，未使用仅返回最新版本或分页的界面查询。Excel 中业务字段前置，成绩、报名、方案、训练复用现有字段定义解码，同时保留完整原始 payload。

`student_edit_pending`、`growth_requests`、`operation_requests` 为三项内部未决/幂等安全状态：仅列源行数及排除原因，不导出正文；SWBACK2 保持完整恢复能力。准备和写出前检查未决编辑、导入、教务及学生写入请求，不自动重放或解决。

`intake_jobs.source_json` 默认不输出；勾选并明确确认后才包含该导入原文。清单准确列出排除列及数量，其他已确认业务和来源身份保留。原文、备注可能含机构自由文本，文件应在本机人工核对、私人保存。本范围不含库外原始 Word/Excel、浏览器、日志或未来附件，也不是 SQLite/SWBACK 的替代副本。

每张工作表及物理列顺序映射见 `export-manifest.json.workbookSheets`，字段中文标题与原字段见“字段映射”表。每表列出原行数、输出行数、实体键/实体数、历史表行数或附加历史版本数；行数不冒充学生或考试实体数。SQL NULL 在 XLSX 中显示 `⟪NULL⟫`，空字符串保留为空白；JSON 保留原始类型。超出安全整数范围的 SQLite 整数使用 `{sqliteInteger: "十进制原值"}` 标签，无精度截断。

## 一致性与写出

复用 `captureProtection` 的固定顺序五库写入保留锁和完整镜像验证。只从受检内存镜像开启 query-only 连接，保留全部业务历史。界面仅收到数量与范围，业务正文不进入 renderer 日志。预览绑定窗口、档案与快照摘要，15 分钟失效，最终写出单次消费；预览后保存的新业务不偷偷加入旧预览。

只向用户选定的仓库外本机 NTFS 新目录写出，拒绝正式程序/档案、链接路径、Git 目录和已有输出目录。新增窄化原生 `publish-business` 命令只允许三种固定文件名，继续使用受检相对句柄、独占新建、flush 和逐文件读回；`export.complete` 最后写入并绑定清单 SHA256。失败或中断不报成功，保留不完整目录，不删除用户文件。取消预览或文件夹选择不会生成成功结果；开始写出后不提供虚假的“已取消”。

原始模型紧凑 JSON 上限 32 MiB，文件合计上限 96 MiB，并检查可用内存与磁盘余量；达到限制明确失败，不截断记录。Excel 每表最多 1,048,575 数据行，加一行标题，超出分表；超长、过多换行、Excel 不支持字符使用有编号的 JSON 字符串分片，配套 JSON 完整保留。所有业务单元格均为显式字符串，不创建公式、链接、宏或外部数据连接。

## 依赖与已知告警

锁定 MIT 许可的 ExcelJS 4.4.0；构建复制其官方自包含发行文件并保留 MIT 声明，不在公开仓库提交 vendor 或生成业务文件。使用发行包是为保持原有不打包 node_modules 的应用边界；原生发布、schema 和 SWBACK2 不变。[官方发行说明](https://github.com/exceljs/exceljs/blob/v4.4.0/README.md#browserify)。

生产依赖审计有 uuid 中危告警（ExcelJS 传递依赖）。公告影响 v3/v5/v6 API 的外部缓冲区写入，v4 不属于该路径；本功能使用 Node crypto 身份生成，ExcelJS 仅在条件格式路径引用无缓冲区参数的 v4，导出也不创建条件格式。记录此适用边界，不将“当前不可达”写成依赖无漏洞，不用强制降级或修改告警判定掩盖结果。[GHSA-w5hq-g745-h8pq](https://github.com/advisories/GHSA-w5hq-g745-h8pq)。
