## 剪贴板安全

默认 `scripts/score-acceptance.cjs` 已完全移除系统剪贴板读取、写入、原生 paste 和恢复代码，无可开启的隐式开关。真实剪贴板粘贴标记为 not-run；非剪贴板输入继续通过 Electron insertText 验证。新增静态回归禁止剪贴板 API 再次进入默认脚本。

因此异常、进程强退、恢复失败以及用户同时更新剪贴板都不会让此脚本读取或覆盖剪贴板；它没有用户原内容可写入日志或文件。此前取证作为历史记录保留，不能据此允许继续在日常会话运行真实剪贴板测试。

真实粘贴只能另行在用户明确批准的独立 Windows 会话人工执行。建议使用仅含虚构内容的一次性测试账户/VM，记录非敏感结果，不采集剪贴板原内容；会话退出时丢弃合成剪贴板，不在工作会话实现“保存后恢复”的测试。当前工作会话没有获得此项授权，本次未执行真实剪贴板操作。
